# 两个孩子成长记录项目设计

## 目标

为两个孩子建立长期、清晰、便于持续维护的成长记录项目，记录共同家庭经历，也分别保存每个孩子的个人成长变化。

## 文件结构

```text
成长记录.md
姚梓凡/
  README.md
  记录/
姚梓歆/
  README.md
  记录/
```

## 文档职责

### `成长记录.md`

作为项目总览，包含家庭记录说明、两个孩子的基本索引、共同成长时间线、家庭目标、重要事件和年度总结。

### `姚梓凡/README.md`

作为姚梓凡的个人成长档案，包含基本信息、成长里程碑、学习情况、兴趣爱好、健康情况、性格变化、亲子记录和后续关注事项。

### `姚梓歆/README.md`

采用与姚梓凡一致的结构，记录姚梓歆的个人成长信息，便于长期维护和回顾。

### `记录/`

用于保存按日期命名的详细成长日志，例如 `2026-09-14.md`。目录先行建立，具体日志按实际需要添加。

## 编写原则

1. 所有内容使用简体中文。
2. 不预填或虚构孩子的年龄、生日、经历和评价。
3. 使用清晰的 Markdown 标题、表格和待填写提示。
4. 记录事实、感受和变化，避免只记录成绩或结果。
5. 两个孩子的个人文档保持大体一致，但允许根据实际情况增加独立栏目。

## 完成标准

- 根目录存在总览文档。
- 两个孩子目录各有一份个人 README 文档。
- 两个孩子目录各有一个用于后续日志的 `记录/` 子目录。
- 文档包含可直接填写的模板，不包含虚构的个人信息。
