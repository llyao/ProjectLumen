# 朵朵数学阶段学习分析设计

## 目标

在 `朵朵/6年级/记录/数学/` 下建立数学学科目录，根据近期可见试卷，对已学习的知识、掌握较好的内容、仍需巩固的内容和提升方法进行客观、可追踪的阶段总结。

## 评价原则

1. 只依据已提供的试卷、批改痕迹和订正情况，不推断未展示的成绩或能力。
2. 区分首次作答、订正后表现和重复出现的错误；订正正确不直接等同于独立掌握。
3. 使用“稳定掌握、基本掌握、需要巩固、证据不足”四种状态，不使用“粗心”“差”“不认真”等笼统标签。
4. 每项评价必须同时提供试卷表现和后续观察标准，方便以后用新试卷更新。
5. 数学能力评价限定在本阶段可见内容，不扩展为性格、智力或教育诊断。

## 知识覆盖范围

根据近期试卷，知识地图至少包括：

- 整除的含义和语言方向。
- 因数、倍数及完整列举。
- 2、3、5的倍数特征。
- 同时满足多个因数或倍数条件。
- 整数、自然数、正整数和负整数分类。
- 素数、素因数、互素。
- 公因数、共同素因数和最大公因数。
- 两数、三数最大公因数的列举法、分解素因数法和短除法。
- 根据短除图反推原数。
- 字母表示的倍数关系和反求字母。
- 因数搭配、长方形种数和数字组数。
- 分组、截绳、总价判断、最少件数、连续偶数和年龄乘积等应用题。
- 列举顺序、单位、答句和卷面自检。

## 初步评价框架

### 掌握较稳定

- 两数和三数的最大公因数短除法：后期多组题目能够正确完成，方法稳定性已有明显提升。
- 基础互素和简单最大公因数判断：多道选择、填空题可以正确完成。

### 基本掌握，仍需观察

- 2、3、5的倍数特征。
- 简单因数、倍数关系判断。
- 因数集合图和基础数的分类：订正后能够完成，但独立作答的完整性仍需用新题确认。

### 需要重点巩固

- 完整列举因数和限定范围内的倍数。
- “既……又……”多条件筛选。
- “能被整除”和“能整除”的语言方向。
- 公因数、共同素因数、最大公因数的区别。
- 根据短除图反推原数，及字母关系迁移。
- 长方形种数、数字组数等有序枚举。
- 文字较长的应用题建模和有效条件提取。
- 过程整理、单位、答句和答案完整性。

## 提升方法

每个薄弱点使用同一结构记录：

| 项目 | 内容 |
| --- | --- |
| 试卷表现 | 描述具体错误或反复出现的现象 |
| 关键原因 | 只分析知识或解题流程，不评价性格 |
| 简单方法 | 提供可以直接执行的口诀或三步法 |
| 练习安排 | 每次少量同类题，完成后口述判断依据 |
| 达标标准 | 用正确率、完整率或连续独立完成次数判断 |

训练优先级为：先补完整列举和概念方向，再练多条件筛选，最后集中练应用题建模和卷面表达。
