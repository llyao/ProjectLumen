# 朵朵语文每周学习资料设计

## 目标

在 `朵朵/6年级/记录/语文/2026-09-14/` 下建立一套轻量、可持续的语文学习资料。学习频率为每周一次，每次约45分钟，覆盖上海六年级语文常见模块，并重点帮助朵朵掌握阅卷得分规律和规范答题方法。

## 信息依据与边界

- 记录对象：朵朵。
- 当前阶段：上海六年级第一学期。
- 近期可确认的学习内容包括《宿建德江》《六月二十七日望湖楼醉书》《西江月·夜行黄沙道中》、宗璞《丁香结》、郭沫若《石榴》、文言文《王华还金》、高尔基《童年》和记叙文写作。
- 学习诊断依据为家长提供的周末卷照片，只用于设计练习重点，不把单次作答推断成长期能力或学习态度。
- 不记录或推断朵朵的真实姓名、学校、班级及其他敏感信息。

## 文件职责

### 00-使用说明.md

说明资料用途、每周45分钟使用顺序、家长陪伴原则和所有文件入口。强调少而持续，不要求每日练习。

### 01-八周语文学习计划.md

每周安排一次45分钟学习：5分钟复习、10分钟方法学习、20分钟真题或真题选段、7分钟订正、3分钟记录。八周依次覆盖作答规范、古诗词、文言文、现代文修辞、现代文概括与结构作用、基础运用与名著、作文审题与选材、综合复习。

### 02-语文解题技巧.md

按模块讲解阅卷得分规律和可直接使用的答题框架，包括：

- 分值与答题点数量的关系。
- 古诗词默写、理解和赏析。
- 文言实词、句子翻译和内容理解。
- 现代文概括题、词句赏析题、句子含义题和段落作用题。
- 选择题常见干扰方式。
- 名著情节判断方法。
- 记叙文审题、选材、描写和结尾照应。
- 不会时如何写出有依据的部分答案，减少空题。

技巧配合《丁香结》《石榴》《王华还金》《童年》和近期古诗词举例，不编造成朵朵的真实经历。

### 03-上海六年级真题资料索引.md

通过公开网页检索上海六年级语文试卷或真题资料。每条资料记录标题、年份、学期、地区或学校、题型范围、来源链接、访问日期和真题可信度说明。

只把能核实年级、学期和来源的信息称为真题。无法确认来源的资料标为“练习参考”，不冒充真题；不复制来源不明或受限制的整套试卷内容。

### 04-每周错题与进步记录.md

提供可重复填写的记录表，记录日期、练习模块、用时、错题原因、订正方法和具体进步。表达保持温和客观，不使用负面标签。

## 每周45分钟流程

| 环节 | 时间 | 做法 |
| --- | ---: | --- |
| 复习 | 5分钟 | 重看上周一至两道错题 |
| 学方法 | 10分钟 | 学习本周一个答题框架 |
| 做真题 | 20分钟 | 完成一组真题或真题选段 |
| 订正 | 7分钟 | 找原文依据并说明错因 |
| 记录 | 3分钟 | 写下一项掌握的方法和一项待巩固内容 |

## 质量检查

- 所有新增内容使用简体中文。
- 文件均位于朵朵六年级的语文学科目录，不修改凡凡资料。
- 所有网页链接在写入前检查可访问性和页面标题。
- 真题索引明确区分真题、公开试卷和普通练习。
- 技巧与上海六年级难度、朵朵近期学习内容相匹配。
- 不承诺押中考试内容，不使用“内部题”“泄题”等误导性表述。
- Markdown 标题、表格、链接和目录引用均可正常阅读。
