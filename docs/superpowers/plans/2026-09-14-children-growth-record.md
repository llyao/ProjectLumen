# 两个孩子成长记录实施计划

> **面向智能代理：** 必须使用 `superpowers:subagent-driven-development` 或 `superpowers:executing-plans`，按任务逐项执行本计划。使用复选框跟踪步骤。

**目标：** 创建一个总览 Markdown 文件、两个孩子的个人 README 文件，以及两个用于后续日志的目录。

**架构：** 根目录总览文档负责共同信息和索引；每个孩子的 README 负责个人成长档案；各自的 `记录/` 目录保存按日期拆分的详细日志。所有文档均使用简体中文，并只保留可填写模板，不虚构个人信息。

**技术栈：** Markdown、Git

---

### 任务 1：创建项目总览文档

**文件：**

- 创建：`成长记录.md`

- [ ] **步骤 1：** 创建总览文档，包含项目说明、两个孩子的索引、共同成长时间线、家庭目标、重要事件和年度总结。
- [ ] **步骤 2：** 检查文档中没有虚构的姓名以外的个人信息，并确认所有内容为简体中文。
- [ ] **步骤 3：** 提交：`git add -- 成长记录.md; git commit -m "docs: 添加孩子成长记录总览"`

### 任务 2：创建姚梓凡个人成长文档

**文件：**

- 创建：`姚梓凡/README.md`
- 创建目录：`姚梓凡/记录/`

- [ ] **步骤 1：** 创建个人成长档案模板，包含基本信息、成长里程碑、学习情况、兴趣爱好、健康情况、性格变化、亲子记录和后续关注事项。
- [ ] **步骤 2：** 创建空的 `记录/` 目录，并通过其中的 `.gitkeep` 文件让目录纳入 Git。
- [ ] **步骤 3：** 检查内容适合长期按日期追加日志，且没有虚构信息。
- [ ] **步骤 4：** 提交：`git add -- 姚梓凡/README.md 姚梓凡/记录/.gitkeep; git commit -m "docs: 添加姚梓凡成长记录模板"`

### 任务 3：创建姚梓歆个人成长文档

**文件：**

- 创建：`姚梓歆/README.md`
- 创建目录：`姚梓歆/记录/`

- [ ] **步骤 1：** 创建与姚梓凡结构一致的个人成长档案模板，并将姓名替换为姚梓歆。
- [ ] **步骤 2：** 创建空的 `记录/` 目录，并通过其中的 `.gitkeep` 文件让目录纳入 Git。
- [ ] **步骤 3：** 检查两个个人文档的栏目一致，同时保留后续按实际情况扩展的空间。
- [ ] **步骤 4：** 提交：`git add -- 姚梓歆/README.md 姚梓歆/记录/.gitkeep; git commit -m "docs: 添加姚梓歆成长记录模板"`

### 任务 4：完成验证

- [ ] **步骤 1：** 运行 `Get-ChildItem -Recurse -File`，确认总览文档、两个 README 和两个 `.gitkeep` 均存在。
- [ ] **步骤 2：** 运行 `git status --short`，确认没有未提交变更。
- [ ] **步骤 3：** 运行 `git log --oneline -5`，确认三个文档提交和设计文档提交均存在。
