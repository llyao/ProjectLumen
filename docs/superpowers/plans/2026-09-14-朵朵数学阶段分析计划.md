### 任务二：写入客观阶段学习分析

**文件：**

- 新建：`D:\ProjectLumen\朵朵\6年级\记录\数学\2026-09-14-数学阶段学习分析.md`

- [x] **步骤1：写明分析范围和证据限制**

明确本次只依据近期八张可见试卷、批改痕迹和订正内容；部分答案经过订正，不能直接视为首次独立掌握；不使用未提供的总成绩和排名。

- [x] **步骤2：建立已学习知识地图**

知识地图分为六组：

1. 整除、因数、倍数和2、3、5的倍数特征。
2. 整数、自然数、正整数、负整数、素数、素因数和互素。
3. 公因数、共同素因数、最大公因数及三种求法。
4. 字母倍数关系、短除图反推和已知最大公因数反求字母。
5. 因数搭配、长方形种数、数字组数和集合分类。
6. 分组、截绳、总价、最少件数、连续偶数和年龄乘积应用题。

- [x] **步骤3：写入总体客观评价和四级状态说明**

总体结论必须包括：基础计算和最大公因数方法正在变稳；主要失分集中在完整列举、概念方向、多条件筛选、知识迁移、应用题建模和正式表达；当前核心不是单纯增加计算量，而是建立固定判断流程。评价统一使用“稳定掌握、基本掌握、需要巩固、证据不足”四种状态。

- [x] **步骤4：记录稳定掌握的内容**

写入两数、三数最大公因数短除法和基础互素判断，并说明后期多组题目正确是主要证据。同时指出“稳定”限定在同类基础题，复杂迁移仍需观察。

- [x] **步骤5：记录基本掌握但需观察的内容**

写入2、3、5倍数特征、简单因数倍数关系、因数集合图和基础数分类。明确部分结论来自订正后表现，需要用无提示新题验证独立完成情况。

- [x] **步骤6：记录证据不足、暂不下结论的内容**

明确一次订正正确不能证明已经稳定掌握；对做题速度、复杂综合迁移和未展示章节不作评价，等待后续无提示新题和新试卷补充证据。

- [x] **步骤7：记录需要巩固的内容和提升方法**

为以下八类分别写“试卷表现、原因判断、简单方法、练习安排、达标标准”：

1. 完整列举因数和限定范围内倍数。
2. 多条件筛选和数字组数。
3. 整除语言方向。
4. 公因数、共同素因数、最大公因数的区别。
5. 短除法反推和字母关系迁移。
6. 因数搭配和完整枚举。
7. 应用题提取有效条件与建模。
8. 卷面自检、过程整理、单位、答句和完整性。

- [x] **步骤8：写入训练优先级与观察标准**

训练按三阶段排列：先补完整列举和概念方向；再练多条件筛选和迁移；最后练应用题与卷面表达。观察标准包括连续两次独立完成、列举完整率、条件使用率、单位答句完整率和能否口述判断依据。
