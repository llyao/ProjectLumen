# 朵朵语文每周学习资料实施计划

> **供智能执行者使用：** 必须使用 `superpowers:executing-plans`，在当前会话中逐项实施并核对结果。

**目标：** 在朵朵六年级语文记录目录中建立按日期归档的八周学习计划、分模块解题技巧、上海六年级真题索引和每周记录模板。

**结构：** 使用一个日期目录集中保存五份 Markdown 文件。计划文件负责安排每周一次、每次45分钟的学习节奏；技巧文件负责讲清阅卷得分规律；真题索引仅收录经过网页核验的公开资料，并清楚标注来源可信度。

**使用工具：** Markdown、PowerShell、Tabbit 浏览器只读检索、Git。

### 任务二：编写八周学习计划

**文件：**

- 新建：`朵朵/6年级/记录/语文/2026-09-14/01-八周语文学习计划.md`

- [ ] **步骤一：写入固定学习流程**

写明每周一次，每次45分钟：复习5分钟、方法学习10分钟、练习20分钟、订正7分钟、记录3分钟。

- [ ] **步骤二：写入八周主题**

八周依次为：作答规范与摸底、古诗词、文言文、现代文修辞赏析、现代文概括与结构作用、基础运用与《童年》、记叙文写作、综合复习。每周必须包含目标、材料、步骤和完成标准。

- [ ] **步骤三：写入难度调整规则**

连续两次完成顺利时只增加一点题量；单次困难时减少题量并重做一道典型题；不因一次结果判断长期水平。

**文件：**

- 新建：`朵朵/6年级/记录/语文/2026-09-14/02-语文解题技巧.md`

使用《石榴》第17至19题、《童年》第20题等已见题型示范规范答案，并说明得分点，不把示范称为学校标准答案。

- [ ] **步骤一：设定收录标准**

候选资料必须能核实“上海、六年级、语文、年份或学期”中的关键信息。优先教育部门、学校公开页面和可核验的试卷页面；来源不充分的资料标为“练习参考”。

- [ ] **步骤二：使用浏览器并行检索候选资料**

至少保留三条有使用价值的候选资料。每条记录标题、适用范围、来源、访问日期、可信度和使用建议；对无法确认正式考试属性的资料明确标注“公开试卷”或“练习参考”。
