## 二、教材导读：这册书要学什么

### 1. 四项英语核心能力

教材希望学生在真实情境中逐步发展四个方面：

1. 语言能力：能听懂、会表达、能阅读、会写作。
2. 文化意识：了解中国文化和世界文化，学会尊重差异。
3. 思维品质：能比较、归纳、判断，并说明理由。
4. 学习能力：会制订计划、使用工具、检查学习效果并调整方法。

### 2. 每个常规单元的学习路径

每个单元由一个主题和一个“大问题”统领，依次训练：

1. 视听：从图片、视频或录音中获取信息。
2. 听力：抓关键词，判断场景和主题。
3. 口语：在真实情境中询问、回答或交流。
4. 阅读：识别文体，提取主旨和细节，进行比较与思考。
5. 写作：围绕主题组织内容，检查语言和格式。
6. 项目探究：合作完成可展示的真实任务。

### 3. 教材特色栏目的作用

| 栏目 | 主要作用 | 学习时要做什么 |
| --- | --- | --- |
| Sound | 发现字母或字母组合的发音规律 | 先朗读，再按读音分类，不能只看拼写 |
| Word study | 通过语义网、搭配、构词法和语境学习词汇 | 把单词放进词组和句子中记忆 |
| Grammar in use | 从语境中发现并运用语法规律 | 先观察例句，再归纳规则，最后造句 |
| TEEN skill | 学习口语、写作、数字安全等实用技能 | 把提示变成答题和交流时的检查步骤 |
| Discovery | 了解文化和跨学科知识 | 比较不同文化，避免只记零散事实 |
| My learning notes | 积累完成任务时可直接使用的表达 | 分类记录并补充自己的例句 |
| To-do list | 明确单元任务并进行阶段性自评 | 完成一个板块后及时检查并打勾 |

## 三、前置单元 Starter 1：认识新朋友

### 1. 主题与能力

- 用英语介绍姓名、兴趣和空闲时间活动。
- 询问他人的基本情况并礼貌回应。
- 复习26个英文字母的大写、小写、顺序和常见发音。
- 为每个字母联想至少一个单词，建立“字母—发音—单词”的联系。

### 2. 核心表达

| 功能 | 表达 | 规则或提示 |
| --- | --- | --- |
| 介绍姓名 | `I’m ...`；`My name is ...` | `I’m` 是 `I am` 的缩写 |
| 介绍兴趣 | `I like doing ...`；`I love doing ...` | `like/love` 后常接动词的 `-ing` 形式 |
| 说明空闲活动 | `In my free time, I like ...` | `in one’s free time` 表示“在某人的空闲时间” |
| 询问姓名 | `What is your name?` | 回答可用 `My name is ...` |
| 询问兴趣 | `What do you like doing in your free time?` | `do` 后面的 `like` 使用原形 |
| 初次见面 | `Nice to meet you.` | 可回答 `Nice to meet you, too.` |
| 询问身份 | `Who am I?` | `who` 询问人或身份 |
| 询问字母顺序 | `What is the fifth letter of the English alphabet?` | `fifth` 是序数词，表示“第五个” |

### 3. 兴趣活动的构词形式

- `sing → singing`
- `write → writing`：去掉词尾不发音的 `e` 再加 `-ing`。
- `run → running`：重读闭音节中，末尾辅音字母双写后加 `-ing`。
- `play → playing`
- `take → taking`：去掉词尾不发音的 `e` 再加 `-ing`。

### 4. 字母与发音意识

- 字母有“字母名称”和“在单词中的实际读音”，二者不能混为一谈。
- 同一个字母在不同单词中可能有不同读音。
- 学习一个新词时，应同时注意拼写、读音、词性、含义和用法。

## 四、前置单元 Starter 2：打开书包与学习英语

### 1. 主题与能力

- 说出书包和教室中的物品。
- 描述物品的位置、数量和所属关系。
- 交流学习单词和提高口语的方法。
- 读懂英汉词典词条，并学会查词典。

### 2. 物品与学习工具词汇

| 类别 | 词汇或词组 |
| --- | --- |
| 书本类 | `book`、`notebook`、`dictionary` |
| 文具类 | `pen`、`pencil case`、`paper` |
| 随身物品 | `schoolbag`、`red scarf` |
| 动作 | `open the bag`、`take out ...`、`put ... on the desk` |
| 状态 | `heavy`、`missing`、`ready` |

### 3. 语法和句型

| 知识点 | 结构 | 提示 |
| --- | --- | --- |
| 表示拥有 | `I’ve got ...` | `I’ve got` 等于 `I have got` |
| 存在句 | `There is + 单数或不可数名词`；`There are + 复数名词` | 谓语形式通常与后面的名词保持一致 |
| 询问内容 | `What’s in your schoolbag?` | `what` 询问事物 |
| 物主代词 | `This bag is mine.` | `mine` 后面不再接名词；`my` 后必须接名词 |
| 代词指代 | `It’s heavy.`；`put them on ...` | `it` 指单数物品，`them` 指复数物品 |
| 附加疑问句 | `This is ..., isn’t it?` | 本阶段认识其“确认信息”作用，完整规则在后续单元学习 |
| 询问方法 | `How can I learn ...?` | `can` 后接动词原形 |
| 表示方式 | `by + 动词-ing` | 例如通过阅读、听录音等方式学习 |

### 4. 英语学习方法

- 输入类：读英语故事、看英语电影、听录音、听英语歌曲。
- 输出类：跟读、朗读、背诵、与自己说英语、与老师同学交流。
- 积累类：记生词本、写英语日记、记录有用表达。
- 原则：语言要在使用中掌握；听、说、读、写需要结合。

### 5. 词典词条的五个维度

查到单词后至少读取：

1. 单词拼写。
2. 读音或音标。
3. 词性，如名词、动词、形容词。
4. 中文含义。
5. 例句和常见用法。

还应注意英式拼写与美式拼写的差异，例如 `favourite` 与 `favorite`。

## 五、前置单元 Starter 3：安排时间

### 1. 主题与能力

- 读懂简单邮件的组成。
- 询问交流对象、交流频率和合适时间。
- 读写课程或一周计划，使用任务清单管理学习。

### 2. 邮件结构

一封基础邮件通常包括：

1. 发件人 `From`。
2. 收件人 `To`。
3. 主题 `Subject`。
4. 问候语。
5. 正文。
6. 结束语和署名。

`Re:` 表示对原邮件主题的回复。朋友间可使用较亲切的问候，但给教师写信时要使用恰当称呼。

### 3. 时间与频率表达

| 类别 | 表达 | 用法 |
| --- | --- | --- |
| 询问频率 | `How often ...?` | 问“多久一次” |
| 频率 | `every day/week/month` | 每天、每周、每月 |
| 间隔 | `every other day` | 每隔一天 |
| 周期 | `every two weeks` | 每两周 |
| 时间范围 | `from 3 to 5 p.m.` | 从下午3点到5点 |
| 时段 | `in the morning/afternoon/evening` | 在早晨、下午、晚上 |
| 星期 | `on Monday`；`on Tuesdays` | 具体某天或每逢周二 |
| 时刻 | `at 3 p.m.` | 具体钟点前用 `at` |

### 4. 计划与学习管理表达

- `make a plan`：制订计划。
- `keep/follow a to-do list`：保留并执行任务清单。
- `complete/finish a task`：完成任务。
- `update the list`：更新清单。
- `review the lesson`：复习课程。
- `read aloud`：大声朗读。
- `keep a weekly journal`：写周记。
- `make next week’s to-do list`：制订下周任务清单。

## 六、前置单元 Starter 4：我准备好了吗

### 1. 情态动词 `can`

- 肯定：`主语 + can + 动词原形`，表示会做或能够做某事。
- 否定：`主语 + cannot/can’t + 动词原形`。
- 一般疑问：`Can + 主语 + 动词原形 ...?`
- 特殊疑问：`What can + 主语 + 动词原形 ...?`
- `can` 不随主语人称变化，后面的实义动词始终使用原形。

### 2. 初中衔接自评内容

- 能写一周七天、四季、十二个月。
- 能写教室物品、动物、颜色和地点等基础词汇。
- 能用英语介绍自己和中国，进行简单交流。
- 能读懂简单图画故事和卡通。
- 能查词典、排列单词组成句子。
- 能在不确定时使用 `Sorry.`、`I don’t know.`、`Please.`、`Thank you.` 等得体表达。

### 3. 学习态度与文化意识

- 英语既是交流工具，也是了解世界和介绍中国的工具。
- 不只判断“会或不会”，还要找出具体需要帮助的项目。
- 自评结果用于决定复习重点，不用于给自己贴标签。

## 七、前置单元的基本句型

### 1. 主语和谓语

- 主语表示句子在说“谁”或“什么”，常由名词、代词或名词词组担任。
- 谓语动词说明主语“做什么”或“发生什么”。

### 2. 三种基本句型

| 句型 | 结构 | 含义 | 自编例句 |
| --- | --- | --- | --- |
| 主谓 | `S + V` | 主语做什么或发生什么 | `The bell rings.` |
| 主系表 | `S + V + C` | 主语是什么或怎么样 | `The dictionary is heavy.` |
| 主谓宾 | `S + V + O` | 主语对宾语做什么 | `I read English stories.` |

### 3. 三个容易混淆的成分

- 系动词：连接主语和状态或特征，常见有 `be`、`look`、`feel`、`get`。
- 表语或补语：说明主语的身份、性质或状态，常由名词或形容词担任。
- 宾语：实义动词动作的接受者，常由名词、代词或名词词组担任。

### 4. 连词成句的操作顺序

1. 找主语。
2. 找谓语或系动词。
3. 判断是否需要宾语或表语。
4. 补时间、地点和方式等其他成分。
5. 检查句首大写、句末标点和动词形式。

1. 最喜欢学校的什么方面，如学科、教师、朋友、社团或活动。

| 人物 | 学生、教师、校长、同学、社团成员 |

## 十一、第1单元词形与构词

### 1. 名词复数

| 单数 | 复数 | 规则 |
| --- | --- | --- |
| `life` | `lives` | `f` 变 `v` 再加 `-es` |
| `activity` | `activities` | 辅音字母加 `y` 结尾，去 `y` 变 `i` 加 `-es` |
| `reply` | `replies` | 辅音字母加 `y` 结尾，去 `y` 变 `i` 加 `-es` |
| `difference` | `differences` | 一般加 `-s` |
| `experiment` | `experiments` | 一般加 `-s` |
| `instruction` | `instructions` | 一般加 `-s` |
| `project` | `projects` | 一般加 `-s` |
| `group` | `groups` | 一般加 `-s` |

朵朵重点：`do experiments`、`different activities`、`follow instructions`、`all the differences` 已在两天练习中重复出现词形问题。写出名词后要检查“可数吗、数量大于一吗、前面是否有 `all`、`many`、`lots of` 或 `different kinds of`”。

### 2. 国家、国家形容词与语言

| 国家名 | 国家形容词或语言 | 单元中的用途 |
| --- | --- | --- |
| `France` | `French` | `French history`、`French schools`、`French` 课程 |
| `Finland` | `Finnish` | 描述芬兰的人、语言或事物 |
| `Mexico` | `Mexican` | 描述墨西哥的人或事物 |
| `Germany` | `German` | 描述德国的人、语言或事物 |
| `China` | `Chinese` | 描述中国的人、语言或事物 |

朵朵重点：国家名表示地点，国家形容词修饰名词。应写 `go to France`，但写 `French history`，不能把两个位置都写成同一种形式。

### 3. 常见词族

| 基础词 | 相关形式 | 关系 |
| --- | --- | --- |
| `instruct` | `instruction`、`instructions` | 动词变名词，实际语境中常用复数 |
| `act` | `activity`、`activities` | 动词词根到名词及其复数 |
| `different` | `difference`、`differences` | 形容词与名词 |
| `week` | `weekly` | 名词变形容词或副词 |
| `laboratory` | `lab` | 全称与简写 |
| `information and communications technology` | `ICT` | 全称与缩写 |

## 十二、第1单元发音：字母 i

同一个字母 `i` 在不同单词中不只一种读音，必须以完整单词的读音为准。

| 读音 | 发音特点 | 单元或练习中的例词 |
| --- | --- | --- |
| `/ɪ/` | 短元音，短而放松 | `fish`、`animal`、`history`、`music`、`bring`、`experiment`、`instruction` |
| `/aɪ/` | 双元音，由前向后滑动 | `hi`、`life`、`science`、`timetable`、`kite`、`write`、`bicycle`、`nice` |
| `/iː/` | 长元音，声音较长 | `police` 等少数词；需要按词记忆 |

朵朵重点：辨音题不能使用“都含字母 `i`，所以发音相同”的判断方法。正确步骤是：逐词朗读或回忆音标→标出目标音→按声音分组→最后核对是否漏选或多选。

## 十三、第1单元核心语法：一般现在时

### 1. 主要用途

一般现在时用于表达：

1. 习惯和日常安排，如每天、每周经常做的事。
2. 按时间表进行的事件，如上课、放学、校车到达。
3. 现在成立的状态，如来自某地、喜欢某学科。
4. 普遍事实和客观真理。

常见时间提示有 `every day`、`every week`、`usually`、`often`、`on Mondays`、`at noon`。

### 2. 实义动词肯定句

| 主语 | 谓语形式 | 例句 |
| --- | --- | --- |
| `I/You/We/They` 或复数主语 | 动词原形 | `They play football.` |
| `He/She/It`、单个人名或单数名词 | 动词第三人称单数 | `The lesson starts at nine.` |

`everyone` 虽然表示很多人，但语法上是第三人称单数：`Everyone likes the club.`

### 3. 动词第三人称单数变化

| 动词类型 | 变化 | 示例 |
| --- | --- | --- |
| 大多数动词 | 加 `-s` | `like → likes`、`start → starts` |
| 以 `s、x、sh、ch` 结尾 | 加 `-es` | `miss → misses`、`wash → washes`、`watch → watches` |
| 辅音字母加 `y` 结尾 | 去 `y` 变 `i` 加 `-es` | `cry → cries` |
| 以 `o` 结尾 | 通常加 `-es` | `go → goes`、`do → does` |
| 不规则形式 | 特殊变化 | `have → has`、`be → is` |

### 4. 否定句

| 主语 | 结构 |
| --- | --- |
| `I/You/We/They` 或复数主语 | `主语 + do not/don’t + 动词原形` |
| `He/She/It` 或第三人称单数主语 | `主语 + does not/doesn’t + 动词原形` |

朵朵重点：`doesn’t` 已经承担第三人称单数标记，后面的动词必须恢复原形。正确写法是 `doesn’t love`，不能写 `doesn’t loves`。

### 5. 一般疑问句

| 主语 | 结构 | 简短回答 |
| --- | --- | --- |
| 非第三人称单数 | `Do + 主语 + 动词原形 ...?` | `Yes, ... do.`；`No, ... don’t.` |
| 第三人称单数 | `Does + 主语 + 动词原形 ...?` | `Yes, ... does.`；`No, ... doesn’t.` |

有 `does` 时，句中的实义动词仍用原形。例如 `What does the club do?`，第二个动词不能写成 `does`。

### 6. 特殊疑问句

基本结构：`特殊疑问词 + do/does + 主语 + 动词原形 + 其他成分?`

| 疑问词 | 询问内容 | 示例结构 |
| --- | --- | --- |
| `what` | 什么 | `What does the club do?` |
| `when` | 何时 | `When does school start?` |
| `where` | 哪里 | `Where do they have class?` |
| `why` | 为什么 | `Why do you like it?` |
| `how` | 怎样 | `How do you go to school?` |
| `what time` | 几点 | `What time does school end?` |
| `how often` | 多久一次 | `How often do you play football?` |
| `how many` | 多少可数事物 | `How many lessons do you have?` |

朵朵重点：数量问句使用 `How many + 复数名词 + do/does/can + 主语 + 动词原形 ...?`。`lessons` 必须紧跟在 `How many` 后，不能放到主语后面。

### 7. `be` 动词的一般现在时

- 肯定：`I am`；`you/we/they are`；`he/she/it is`。
- 否定：在 `am/is/are` 后加 `not`。
- 疑问：把 `am/is/are` 放到主语前。
- 含 `be` 动词的句子不再使用 `do/does` 构成否定和疑问。

### 8. 一般现在时检查顺序

1. 圈出时间词，判断是否表达日常、安排、状态或事实。
2. 找主语，判断是否为第三人称单数。
3. 看句中是否已有 `do/does/don’t/doesn’t`。
4. 决定实义动词用原形还是第三人称单数。
5. 最后检查拼写和标点。

## 十四、第1单元其他语法和句法知识

### 1. 情态动词 `can` 和 `may`

- `can/may + 动词原形`。
- `May I ask ...?` 比较正式、礼貌。
- `Can I ask ...?` 也可以用于日常询问。
- `How many students can join ...?` 中，`join` 不变化。

### 2. `there be` 结构

- `There is + 单数或不可数名词`。
- `There are + 复数名词`。
- 用来说明某处有某人或某物，不等同于表示拥有的 `have`。

### 3. 复合修饰语

`数词 + 单数名词` 可以用连字符组成复合修饰语：

- `a fifteen-minute break`
- `a five-minute break`
- `a ten-year-old student`
- `a twenty-page book`

朵朵重点：无论数词是否大于一，中间的计量名词都使用单数，不能写 `five-minutes break`。

### 4. 比较相同与不同

- `A is the same as B.`：A与B相同。
- `A is different from B.`：A与B不同。
- `the differences between A and B`：A与B之间的差异。
- `How is A different from B?`：A与B有何不同？
- `What is similar?`：有什么相似之处？

### 5. `more` 与 `most`

- `more` 表示“更多”，带有比较含义。
- `most` 表示“最、最大程度”。
- `What do you like most about school?` 询问最喜欢学校的哪一点。

### 6. 常用连接结构

- `both A and B`：A和B两者都。
- `A, but B`：表示转折或对比。
- `A, too`：也，通常放在肯定句句末。
- `at the same time`：同时。
- `in this way`：用这种方式。

## 十五、第1单元重点搭配

### 1. 动词与名词搭配

| 动词 | 常见搭配 |
| --- | --- |
| `do` | `do experiments`、`do projects` |
| `make` | `make a game`、`make a word cloud`、`make notes` |
| `have` | `have a class/lesson`、`have a break`、`have a club activity` |
| `play` | `play a game`、`play football`、`play ping-pong` |
| `take` | `take a break`、`take notes`、`take turns` |
| `join` | `join a club`、`join us` |
| `receive` | `receive a reply` |
| `start` | `start a topic`、`school starts at ...` |

### 2. 介词和固定结构

- `learn more about ...`
- `ask questions about ...`
- `open to Grades 6—9`
- `on the football field`
- `in Room 103`、`in the lab`
- `after school`
- `from ... to ...`
- `during the break`
- `at noon`
- `outside the classroom`
- `differences between A and B`
- `at the same time`
- `at the age of ...`

### 3. 容易混淆的搭配

- `join + 社团或人群`，如 `join the club`。
- `take part in + 活动`，如 `take part in an activity`。
- `on` 表示接触某物表面，如 `put your hands on your head`。
- `during + 名词`，不能直接接完整句子。
- `at noon` 是固定搭配，不说 `in noon`。

## 十六、听力与课堂指令

### 1. 听关键词判断学科

听课堂指令时先记录能直接指向学科的词：

- `experiment`、`water` 常指向科学课。
- `ball`、`football`、`exercise`、`turn`、`hand`、`head`、`body` 常指向体育课。
- 还可根据数字、地图、乐器、颜料等词判断数学、地理、音乐或艺术课。

### 2. 课堂指令的语言特点

- 常使用祈使句，句首直接用动词原形。
- 祈使句的主语 `you` 通常省略。
- 听题时不必逐字翻译，先抓“动作词＋物品或身体部位”。

### 3. 朵朵可执行的听力步骤

1. 第一遍确定场景和学科。
2. 第二遍记录动作、物品、数字或地点关键词。
3. 用关键词说明判断依据。
4. 检查答案是否与所有关键词一致。

## 十七、口语：礼貌询问学校活动

### 1. 称呼教师

- 当面称呼：`Mr/Ms/Miss/Mrs + 姓氏`。
- 书信或邮件开头：`Dear Mr/Ms/Miss/Mrs + 姓氏`。
- 不确定婚姻状况时，称呼女教师通常可以使用 `Ms`。

### 2. 礼貌开始提问

- `Excuse me.`
- `May I ask some questions about ...?`
- `Can I ask some questions about ...?`
- `Could you tell me ...?`

### 3. 要询问的信息维度

阅读社团海报或现场咨询时，应覆盖：

- `What`：做什么活动。
- `When/What time`：何时开始、结束。
- `Where`：地点。
- `Who`：面向哪些年级或哪些学生。
- `How many`：招收多少人。
- `How long`：持续多长时间。
- `How`：怎样加入。

### 4. 回应和确认

- `Yes, of course.`
- `I see.`
- `Let me see.`
- `I got it.`
- `Thanks a lot.`
- `You’re welcome.`

## 十八、阅读：网络帖子与学校生活

### 1. 网络帖子的文体组成

一个网络帖子可能包含：

- 话题 `topic`
- 用户名 `username`
- 日期
- 信息正文 `message`
- 表情符号 `emoji`
- 回复 `reply`
- 点赞 `like`
- 评论 `comment`

### 2. 阅读主旨

阅读学校生活帖子时，要回答“这个学校生活最特别的地方是什么”，不能只摘抄一个孤立细节。通常从上课时间、学科、学习方式、课间活动和个人感受几个维度概括。

### 3. 细节信息表

| 信息维度 | 常见提问 | 定位线索 |
| --- | --- | --- |
| 人物 | `Who ...?` | 姓名、用户名、人称代词 |
| 地点 | `Where ...?` | 城市、国家、地点介词 |
| 时间 | `When/What time/How long ...?` | 日期、钟点、时间范围、时长 |
| 学科 | `What subjects ...?` | 学科名称和列举标志 |
| 活动 | `What does ... do?` | 动词与名词搭配 |
| 原因 | `Why ...?` | `because`、评价词和前后逻辑 |
| 异同 | `What is different/similar?` | 两个对象的对应信息 |

### 4. 阅读依据定位法

朵朵重点：

1. 圈出题目中的提问词和关键词。
2. 回原文找同词、近义表达、数字或介词短语。
3. 画出能直接支持答案的句子。
4. 判断题目问的是日期、地点、活动、交通方式还是原因。
5. 用简短完整句作答；没有唯一答案的开放题也不要留空。

## 十九、写作：介绍学校生活

### 1. 内容结构

可以按四段或四个信息块组织：

1. 基本背景：所在城市或地区，不写具体学校名称。
2. 学校日程：开始时间、结束时间、每天课程数量。
3. 学科与活动：喜欢的学科、社团或运动。
4. 感受与理由：最喜欢什么，为什么。

### 2. 可用句型骨架

- `I live in ...`
- `My school day starts at ... and ends at ...`
- `We have ... lessons every day.`
- `My favourite subject is ...`
- `There are ... after-school clubs.`
- `I join/play/go to ... on ...`
- `I like ... most because ...`

以上只作为句型骨架，写作时应替换为自己的真实但不敏感的信息。

### 3. 写作语言检查

- 句首使用大写字母。
- 陈述句末使用句号，疑问句末使用问号，感叹句末使用感叹号。
- 学科、星期、月份、国家和语言名称注意大写。
- 每句检查主语和谓语是否完整。
- 检查一般现在时和第三人称单数。
- 检查名词单复数和固定搭配。

### 4. 网络安全

- 不公开真实姓名、学校名称、班级、住址、家庭详情和联系方式。
- 使用不暴露身份的用户名。
- 不轻信网上读到或听到的所有信息。
- 本项目内只使用“朵朵”，不补充或推测敏感信息。

### 1. 三个步骤

## 二十二、朵朵本章重点：与两天错题的对应

| 优先级 | 知识点 | 已观察到的表现 | 本章订正动作 |
| --- | --- | --- | --- |
| 1 | 名词复数 | `experiment`、`activity`、`instruction`、`difference` 连续出现词形问题 | 每题做“数量提示词＋复数词尾”检查 |
| 1 | 国家名和国家形容词 | `France` 与 `French` 混淆，且 `French` 拼写不稳 | 成对口头造句：去某国、某国的课程或历史 |

| 1 | 数量疑问句语序 | `How many` 后没有紧接复数名词 | 固定按“疑问词组—助动词—主语—原形”排列 |
| 1 | 字母 `i` 发音 | `/ɪ/` 与 `/aɪ/` 多次错选、漏选 | 逐词朗读分类，再查漏选和多选 |
| 2 | 长句组织 | 连词成句只写开头或整题留空 | 先找主语、谓语，再补宾语和状语 |
| 2 | 阅读依据定位 | 日期、地点、活动、交通和问答题定位不稳 | 每题必须画出原文唯一依据 |
| 2 | 答题完整性 | 多道阅读问答和长句留空 | 先写能确定的简短完整答案，最后再完善 |
| 3 | 时间与时态 | 容易忽略时间词对动词形式的提示 | 先圈时间词，再判断时态；本章重点掌握一般现在时 |
