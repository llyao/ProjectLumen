# 朵朵英语错题集

## 目录说明

- `MD/`：按试卷编号保存错题 Markdown。每份记录保留原题、朵朵原答案、正确答案和错误解析。
- `Word/`：按试卷编号保存错题订正本。每份只保留原题、朵朵原答案、空白订正区和空白心得区，方便朵朵重新书写。
- `历史资料/`：整理前的旧版 Markdown、Word、PDF 和图片，仅作历史留存。
