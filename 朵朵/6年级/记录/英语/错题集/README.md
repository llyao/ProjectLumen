# 朵朵英语错题集

## 目录说明

- [MD/](MD/)：每份试卷保存一份完整错题记录，包含题目、原答案、正确答案和错误解析。
- [Word/](Word/)：每份试卷保存一份打印订正本，包含题目、原错误答案或未完成状态，订正和心得留空，不显示正确答案、解析或照片中的订正答案。
- `历史资料/`：整理前的旧版 Markdown、Word、PDF 和图片，仅作历史留存。

## 统一格式

1. 文件名使用 `MD/Lxxx-英语错题集.md` 和 `Word/Lxxx-英语错题订正本.docx`，同一试卷只维护一对当前文件。
2. 保留原试卷大题标题、章节顺序和小题题号，不按知识点重新排序，不把原第 5、8、11 题改成第 1、2、3 题。
3. 每道错题保留完整题干、选项、音标、划线部分和必需的上下文，不单独摘出脱离原文的填空。
4. 阅读、完形或首字母阅读中有错题或未完成题时，保留该篇完整文章、表格及全部小题。随篇保留的小题也留订正空间，但不虚构错误答案。
5. MD 中每道实际错题使用 `**朵朵原答案：**`、`**正确答案：**`、`**错误解析：**`。小题标题统一使用 `**原题号.**`；不同大题的相同题号分别保留。
6. Word 直接按照对应 MD 的顺序生成；只显示原错误作答，不能显示正确答案、解析或已写好的心得。
7. 短选项排在同一行；放不下时排成两列或逐行。句型转换和阅读问答留两行订正，其他题留一行订正；心得一行留空。
8. 无法辨认的原作答写“无法辨清”，未作答如实标注；不根据空白题库推断孩子没有作答。待核对内容留在 MD，不放入打印本。

## 打印设置

- 按普通作业本大小采用 **A5（148×210 毫米）**，正文 **10.5 磅**，中文宋体，英文新罗马字体；菜单等表格为 9.5 磅。
- 打印选择 A5、实际大小或 100%，避免再缩小。可使用 A4 纸每张打印 2 页，得到相近的作业本版面。
- 历史资料仅留存；当前使用 `MD/` 和 `Word/` 下的版本。
