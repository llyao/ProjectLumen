# 第4天：一般现在时肯定句与第三人称单数

日期：__________　完成用时：__________

## 一、今天要学什么（30分钟）

### 1. 一般现在时的用途

本单元主要表示：习惯、日常安排、时间表、现在的状态和普遍事实。

常见提示词：`every day`、`every week`、`usually`、`often`、`on Mondays`、`at noon`。

### 2. 动词形式

- `I/You/We/They` 或复数主语：动词原形。
  - `They play football.`
- `He/She/It`、一个人的名字或单数名词：动词第三人称单数。
  - `The lesson starts at nine.`
- `everyone` 按第三人称单数处理。
  - `Everyone likes the club.`

### 3. 第三人称单数变化

- 一般加 `-s`：`like → likes`
- 以 `s/x/sh/ch` 结尾加 `-es`：`watch → watches`
- 辅音字母加 `y`：`cry → cries`
- 以 `o` 结尾通常加 `-es`：`go → goes`、`do → does`
- 特殊：`have → has`、`be → is`

# 第5天：否定句、疑问句与 How many 语序

日期：__________　完成用时：__________

## 一、今天要学什么（30分钟）

### 1. 否定句

- `I/You/We/They + don’t + 动词原形`
- `He/She/It + doesn’t + 动词原形`

注意：`doesn’t` 已经表示第三人称单数，后面的动词必须用原形：

`She doesn’t love ...`，不能写成 `She doesn’t loves ...`。

### 2. 一般疑问句

- `Do + I/you/we/they + 动词原形 ...?`
- `Does + he/she/it + 动词原形 ...?`

简短回答：`Yes, ... do/does.`；`No, ... don’t/doesn’t.`

### 3. 特殊疑问句

固定骨架：

`疑问词 + do/does + 主语 + 动词原形 + 其他？`

数量问句：

`How many + 复数名词 + do/does/can + 主语 + 动词原形？`

例：`How many lessons do they have every day?`

### 4. `can` 和 `may`

`can/may + 动词原形`：`How many students can join the club?`

# 一周结束后的间隔复习

第10天、第14天和第21天各复习10—15分钟：

1. 听写5个重点词形；
2. 完成3道一般现在时或问句题；
3. 完成1道阅读问答，并画出原文依据；
4. 检查是否仍然做到不留空。

同一知识点连续两次独立答对后，可以减少复习次数，把时间留给仍然容易出错的内容。
