# 朵朵六年级数学记录

## 目录用途

本目录用于保存朵朵六年级阶段的数学学习分析、专项练习、错题复盘和阶段进步记录。

记录重点是知识掌握过程和可观察的变化，不进行成绩排名，也不使用一次考试结果给朵朵下固定结论。

## 后续资料分类建议

- 阶段分析：按日期记录一段时间内学过的知识、掌握状态和下一步重点。
- 专项练习：按知识点保存练习内容，例如因数倍数、最大公因数和应用题。
- 错题复盘：记录错误类型、订正方法和再次练习结果，不只抄写正确答案。
- 进步记录：记录能够独立完成的新题型、错误减少情况和方法使用情况。

## 更新原则

1. 只根据可见试卷、练习和实际表现记录，不补充未提供的信息。
2. 区分首次作答、订正后完成和后来独立掌握。
3. 评价使用“稳定掌握、基本掌握、需要巩固、证据不足”，并写明依据。
4. 新的试卷出现后，优先追加新的日期记录，不覆盖原有阶段分析。
5. 文件中只使用“朵朵”这一称呼，不记录敏感身份信息或联系方式。
