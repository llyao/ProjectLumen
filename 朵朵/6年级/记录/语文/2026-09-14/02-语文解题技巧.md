# 上海六年级语文解题技巧

这些技巧来自常见阅卷评分方式，作用是把已经想到的内容准确写成得分点，不是押题或“内部答案”。

## 一、先看懂题目在要什么

做主观题前先看三处：

1. **看范围：** “第②段”“结合全文”“联系上下文”决定去哪里找答案。
2. **看任务词：** “概括”回答写了什么；“赏析”回答怎样写、好在哪里；“作用”还要回答对结构或主题有什么影响。
3. **看分值：** 分值通常暗示需要多个得分点，但不是机械地“一分一句”。3分题尽量准备两至三个不同信息，4分赏析题通常需要把手法、内容、效果和情感写清。

### 通用答题顺序

**定位原文 → 圈关键词 → 判断题型 → 列得分点 → 写成通顺句子。**

能分点时用“①②③”，阅卷老师更容易看见不同信息。

## 二、古诗词

### 1. 默写题

**技巧：** 写完后倒着逐字检查，重点看同音字、形近字、漏字和语序。

近期容易用到的检查：

- “野旷天低树”的“旷”不能写成“广”。
- “黑云翻墨未遮山”的“遮”不能漏写。
- “卷地风来忽吹散”不要把“忽”写成“呼”。

### 2. 画面题

答题框架：

> 诗句描绘了＿＿时间、＿＿地点，＿＿景物呈现出＿＿状态的画面，营造了＿＿氛围。

不要只把诗句翻译一遍，要把零散景物组合成画面。

### 3. 情感题

先找情感词，再看意象和背景。答案写“情感＋依据”，例如：

> “野旷天低树，江清月近人”通过空旷原野、清江孤月，表现诗人的羁旅愁思。

### 4. 选择题常见陷阱

- 把想象中的丰收写成“已经丰收”。
- 把蛙声误说成人们热烈交谈。
- 把“以声衬静”说成“环境喧闹”。
- 只解释一句，不顾整首词的情境。

## 三、文言文

### 1. 实词解释

不能只写现代汉语中最熟悉的意思，要放回句子判断。

| 原句中的词 | 语境义 | 容易误写 |
| --- | --- | --- |
| 去 | 离开 | 回去 |
| 遗 | 遗留、落下 | 送给 |
| 度 | 估计、推测 | 度过 |
| 复 | 再、又 | 恢复 |
| 谢 | 道谢 | 谢绝 |

### 2. 翻译句子

使用四步法：

1. 圈出必须翻译的关键词。
2. 逐词直译，不先凭感觉写大意。
3. 补出省略的主语、宾语。
4. 调整成现代汉语语序。

以《王华还金》“华度其醒必复来”为例：

> 王华估计那个人酒醒后一定会再回来。

得分点通常包括“度＝估计”“其＝那个人”“复＝再”。

### 3. 人物品质

答题框架：

> 从＿＿行为可以看出人物＿＿、＿＿的品质。

《王华还金》中，王华保护并归还失物、拒绝酬谢，可以概括为拾金不昧、诚实守信；把金子投入水中防止被别人拿走，也体现考虑周全。

## 四、现代文阅读

### 1. 概括题

写事文章使用：

> 谁＋在什么情况下＋做了什么＋结果怎样。

写景文章使用：

> 写了什么景物＋景物有什么特点＋作者有什么感受。

概括后检查：是否漏了关键结果？是否抄了太多修饰语？

### 2. 词语或加点字赏析

答题框架：

> “＿＿”本来表示＿＿，这里写出了＿＿的动作或状态，突出＿＿特点，表达作者＿＿之情。

《丁香结》中“探”“窥”把丁香当作人来写，写出丁香从墙头伸出、仿佛观察行人的情态，表现其俏皮可爱和勃勃生机，也表达作者的喜爱。只写“用了拟人，很生动”通常不够完整。

### 3. 修辞赏析题

四步口诀：**点手法、说对应、写特点、落情感。**

答题框架：

> 这句话运用＿＿和＿＿，把＿＿比作／写成＿＿，生动突出＿＿特点，表达作者＿＿之情，并具有＿＿的表达效果。

《石榴》“那可不是夏季的心脏吗？”可这样回答：

> 运用比喻和反问，把不畏炎阳、颜色深红的石榴花比作“夏季的心脏”，突出石榴花热烈、旺盛而富有生命力，表达作者的喜爱和赞美，并增强语气和感染力。

### 4. 句子含义题

不要只换一种说法重复原句。按两层回答：

1. **表层：** 句子在文中直接说了什么。
2. **深层：** 它说明怎样的人生道理或作者态度。

《丁香结》中“结，是解不完的；人生中的问题也是解不完的”可以理解为：人生总会遇到不顺心的问题；正因为不断面对和解决这些问题，生活才丰富而有滋味，表现作者从容、豁达的人生态度。

### 5. 段落作用题

先根据位置判断，再结合具体内容，不能只写“承上启下”。

| 位置 | 常见结构作用 |
| --- | --- |
| 开头 | 点题、总领全文、设置悬念、引出下文 |
| 中间 | 承接上文、引出下文、形成对比、推动情节 |
| 结尾 | 总结全文、照应开头或题目、点明或深化主题、留下余味 |

答题框架：

> 内容上写了＿＿，表现／表达了＿＿；结构上＿＿；表达效果上＿＿。

《石榴》结尾“禁不住唾津的潜溢了”可答：从侧面突出昆明石榴味美，表现作者对石榴的喜爱和向往；收束全文；以含蓄幽默的语言结尾，给人回味。

### 6. “戏法”一类指代题

先向前找变化过程，再向后找结果。《石榴》中的“戏法”不是普通的魔术，而是石榴由花到果、成熟裂开并露出晶莹籽粒的变化。回答时要写清完整变化，不能只写“石榴开花”。

## 五、选择题的五类陷阱

每个选项都和原文逐项核对：

1. **对象偷换：** 原文写作者，选项换成读者或另一个人物。
2. **时间偷换：** “将要”变成“已经”，“有时”变成“一直”。
3. **范围扩大：** “少数”变成“全部”，“可能”变成“一定”。
4. **因果颠倒：** 原因和结果说反。
5. **无中生有：** 说法听起来合理，但原文没有依据。

选择后不要只问“这个像不像对的”，要问“另外三个分别错在哪个词”。

## 六、名著阅读《童年》

### 人物—事件卡片法

| 人物 | 典型事件或特点 |
| --- | --- |
| 外祖父 | 性格专横；因阿廖沙染坏桌布而惩罚他 |
| 外祖母 | 慈爱善良；擅长讲民间故事，给予阿廖沙温暖 |
| “好事情” | 外祖父家的房客，喜欢做实验，后来被赶走 |
| 舅舅米哈伊尔 | 因争夺家产闹事 |

判断题看到两个事实连在一起时，要分别检查。例如“好事情是房客”与“最后被外祖父赶走”都要核对，不能因为其中一句熟悉就整句判错。按常见版本，外祖母擅长讲民间故事，不能把未经原著支持的具体《圣经》故事直接安到她身上。

## 七、记叙文写作

### 1. 审题三圈

圈出：**写作对象、限制词、中心词。**

“阳光明媚的日子”既可以写真实天气，也可以把“阳光”写成温暖、鼓励和成长，但正文必须让读者看出题目与事件的联系。

### 2. 五分钟提纲

写四句话即可：

1. 谁和谁发生了什么事？
2. 事情为什么对“我”重要？
3. 最值得详细写的场景是什么？
4. 结尾怎样回扣题目？

### 3. 场景描写

重点场景至少选择三种描写：动作、语言、神态、心理、环境。不要每种都写一句硬凑，要让描写服务于人物变化。

### 4. 结尾检查

- 有没有回应题目中的关键词？
- 有没有写出事件后的认识或变化？
- 能否删掉“这件事让我终身难忘”之类空泛套话，换成具体感受？

## 八、不会时的30秒保底方法

1. 再读题干，圈出题型词和范围。
2. 回到原文抄下最相关的关键词。
3. 先写确定的信息，再补手法或作用。
4. 赏析题即使不能完整分析，也先写准确的手法和具体内容。
5. 作用题至少写“内容上写了什么”，不要只空着。

## 九、交卷前一分钟检查

- [ ] 古诗默写是否有同音字、漏字？
- [ ] 文言翻译的关键词是否落实？
- [ ] 阅读答案是否写出了具体内容，而不只是术语？
- [ ] 3分、4分题是否只有一句非常笼统的话？
- [ ] 是否还有空题或只写了一半的句子？
- [ ] 作文题目、开头和结尾是否互相照应？
